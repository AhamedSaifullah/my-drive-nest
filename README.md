## Description

[Nest](https://github.com/nestjs/nest) framework TypeScript starter repository.

## Project setup

```bash
$ npm install
```

## User API

Create a `.env` file from `.env.example` with your MongoDB Atlas connection string and a private JWT secret. Do not commit `.env` or expose the Atlas password in source control:

```env
MONGODB_URI=mongodb+srv://<username>:<password>@<cluster-host>/nest_demo?retryWrites=true&w=majority
JWT_SECRET=replace-with-a-long-random-secret
PORT=3000
```

Start the API with `npm run start:dev`. The following routes are available in Postman:

### Create user

`POST http://localhost:3000/user/create-user` with JSON body:

```json
{
  "firstName": "John",
  "lastName": "Doe",
  "dob": "1995-05-20",
  "gender": "male",
  "email": "john@example.com",
  "phone": "+919876543210",
  "password": "Password123",
  "conf_password": "Password123"
}
```

### Login user

`POST http://localhost:3000/user/login-user` with JSON body. `username` accepts either the registered email or phone:

```json
{
  "username": "john@example.com",
  "password": "Password123"
}
```

The response contains `access_token`. For details, call `GET http://localhost:3000/user/details` and set Postman authorization to `Bearer Token`, using that token. No request body is required.

### Update user

`PATCH http://localhost:3000/user/update-user` with the same Bearer token and any fields to update:

```json
{
  "firstName": "Ahamed",
  "lastName": "Saifullah",
  "gender": "Male",
  "phone": "+919876543210"
}
```

Password changes require both `password` and `conf_password`.

### Logout

`POST http://localhost:3000/user/logout` with the same Bearer token and no request body. The token is revoked for the current application process.

Passwords are hashed before storage and never returned by the API.

## Compile and run the project

```bash
# development
$ npm run start

# watch mode
$ npm run start:dev

# production mode
$ npm run start:prod
```

## Run tests

```bash
# unit tests
$ npm run test

# e2e tests
$ npm run test:e2e

# test coverage
$ npm run test:cov
```

## Deployment

When you're ready to deploy your NestJS application to production, there are some key steps you can take to ensure it runs as efficiently as possible. Check out the [deployment documentation](https://docs.nestjs.com/deployment) for more information.

If you are looking for a cloud-based platform to deploy your NestJS application, check out [Mau](https://mau.nestjs.com), our official platform for deploying NestJS applications on AWS. Mau makes deployment straightforward and fast, requiring just a few simple steps:

```bash
$ npm install -g @nestjs/mau
$ mau deploy
```

With Mau, you can deploy your application in just a few clicks, allowing you to focus on building features rather than managing infrastructure.
